# Prof2IT — JavaScript

Практичні завдання курсу «JavaScript: від основ до практичного застосування».

[Сторінка курсу](https://itcluster.drived.space/uk/learner/course/8c04eaa3-d3b2-4f03-71b7-ddbc53070043/kurs-prof2it-javascript-vid-osnov-do-prakticnogo-zastosuvanna-6a969eb262520)

## Організація завдань

Кожне завдання зберігається в окремій папці: `homework-01`, `homework-02` тощо. Папки додаються в міру виконання робіт. Якщо курс задає інші назви або структуру, використовуються вимоги курсу.

У папці завдання розміщуються:

- файли розв’язання (`.js`, а за потреби — `.html` та `.css`);
- `README.md` з коротким описом та інструкцією запуску;
- потрібні для роботи ресурси.

## Подання роботи

1. Додати або оновити файли відповідного завдання.
2. Зберегти зміни окремим комітом, наприклад `Add homework 01`.
3. Перевірити, що файли доступні на GitHub.
4. Надіслати на платформі курсу посилання на папку, файл або репозиторій відповідно до вимог завдання.

## Запуск

Спосіб запуску вказується в README кожного завдання: у браузері або через Node.js, залежно від умов роботи.

Не додавайте паролі, токени, файли `.env` та папку `node_modules`.
